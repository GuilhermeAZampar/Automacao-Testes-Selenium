# 🧪 Automação de Testes com Selenium

Projeto desenvolvido em Python utilizando Selenium WebDriver para praticar automação de testes em aplicações web.

Os testes utilizam o site **The Internet**, criado para práticas de automação.

## 🚀 Testes realizados

- Login
- Checkboxes
- Dropdown
- Abas e janelas
- iFrames
- JavaScript Alerts

## 🛠️ Tecnologias

- Python
- Selenium WebDriver
- Google Chrome

## 📚 Conceitos praticados

- Localização de elementos com ID, CSS Selector e XPath
- WebDriverWait e Expected Conditions
- Assertions
- Manipulação de abas e iFrames
- JavaScript Alerts
- Tratamento de exceções
- ChromeOptions

## ▶️ Executando o projeto

Instale as dependências:

```bash
pip install -r requirements.txt
```

Execute:

```bash
python main.py
```
